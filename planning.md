# Development Roadmap - Jellyfin Web Client

## Current Status: ✅ Complete

### Core Features Implemented
- ✅ Jellyfin API integration
- ✅ Library browsing and content discovery
- ✅ Personal file upload system
- ✅ Media playback (audio, video, PDF, images)
- ✅ Responsive web interface
- ✅ Search functionality
- ✅ File categorization and management

---

## 🎯 Phase 1: Quick Wins (IT-Friendly)

### File Management Enhancements
- **Batch Operations**: Select multiple files for bulk delete/download
- **File Rename**: Simple rename functionality for uploaded files
- **Basic Search**: Search within personal uploaded files
- **File Size Display**: Show file sizes in human-readable format
- **Upload Progress**: Better visual feedback during uploads

### User Experience Improvements
- **Loading Indicators**: Clear loading states for all operations
- **Error Messages**: User-friendly error notifications
- **Confirmation Dialogs**: Prevent accidental deletions
- **Keyboard Navigation**: Tab and Enter key support
- **Mobile Optimization**: Better touch interactions

### IT Administration Features
- **Storage Monitoring**: Display used/available disk space
- **Upload Statistics**: Track number and size of files
- **Connection Status**: Real-time Jellyfin server status
- **Simple Logging**: Basic activity log for troubleshooting
- **Configuration Check**: Validate API settings on startup

---

## 🎯 Phase 2: Practical Enhancements

### Media Features
- **Basic Playlists**: Create simple music playlists

- **Fullscreen Video**: Better video player controls
- **Image Gallery**: Improved image viewing experience
- **PDF Navigation**: Page controls and zoom

### File Organization

- **File Sorting**: Sort by name, date, size
- **Recent Files**: Quick access to recently uploaded
- **File Info Panel**: Show detailed file information

### IT Support Features
- **Health Checks**: System status dashboard

- **Backup Reminders**: File backup suggestions
